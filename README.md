One-line entry for the make.fun bounty "Famous Last Words: The Funniest
Epitaph" — the funniest thing someone could put on their own tombstone:
self-aware, a little dark, but warm, with the twist saved for the end.

> Well, this is awkward: I spent my whole life avoiding funerals, and now I'm the guest of honor.

Run it:

```sh
python3 main.py
```

It prints exactly that one line, and nothing else.
